Кнопка-палитра в тулбаре для переключения цветовых схем (s/b/e/l/o) с сохранением выбора и применением до первой отрисовки.

## Решения
- Переключение палитры — **с перезагрузкой страницы**: MSI кэширует семейство темы при загрузке (классы dx-theme-fluent/material на body, E0021 при рантайм-смене), а каждый CSS ~0.7 МБ. Перезагрузка с применением палитры inline-скриптом в head даёт чистое состояние без вспышек.
- В списке — **5 актуальных палитр**: s (текущая, синяя #5486ff), b (fluent синяя #0F6CBD), e (material синяя #03a9f4), l (material фиолетовая #9c27b0), o (material оранжевая #ff5722). Старые p/purple/blue исключены (нет --dx-* переменных и ~47 иконок — интерфейс деградирует); f/orange/dx.material.blue — дубликаты b/o/e.

## Изменения

1. **`src/theme/theme-service.ts`** — расширить сервис:
   - `PaletteId` + `PALETTES` (id, название, акцентный hex) — единый whitelist;
   - localStorage-ключ `app-palette` (валидация по whitelist, дефолт `s`), `currentPalette` ref;
   - `applyPaletteLinks(id)` — ставить `href` обоим link: `#msi-theme-light` → `/msi/{id}.light.css`, `#msi-theme-dark` → `/msi/{id}.dark.css` (disabled-состояние остаётся под управлением setAppTheme);
   - `setAppPalette(id)` — сохранить + применить href + `window.location.reload()`;
   - при инициализации (вызов из main.ts) идемпотентно применять сохранённую палитру.

2. **`index.html`** — дописать inline-скрипт анти-FOUC: читать `app-palette`, валидировать по тому же списку, выставлять href обоим link до включения dark-ссылки (внутри существующего try/catch). Иначе после Ctrl+F5 всегда вернулась бы палитра s.

3. **Новый `src/components/library/palette-switcher.vue`** — `dx-drop-down-button` (обёртка `src/msi-vue/drop-down-button` уже используется в header-user.vue): icon `palette` (глиф есть в наборе), пункты = PALETTES с цветным кружком через itemTemplate (если обёртка не поддерживает шаблоны — текстовые названия + иконка кнопки, окрашенная в акцент текущей палитры), текущая палитра помечена; клик → `themeService.setAppPalette(id)`.

4. **`src/components/library/app-header.vue`** — добавить пункт `<palette-switcher />` в правую зону тулбара сразу после `<theme-switcher />` (там же, строки 57–62).

## Ожидаемое поведение и примечания
- Выбор цвета → мгновенная перезагрузка с новой палитрой; тема день/ночь сохраняется и работает с любой палитрой; выбор живёт в localStorage между сессиями.
- Материальные палитры (e/l/o) меняют семейство fluent→material: после перезагрузки msi.js сам переставит классы body, fluent-оверрайды из styles.scss (шрифт Inter и т.п.) к ним не применятся — это ожидаемое поведение тем.
- Прод-сборку dist делаем отдельно по вашей команде.
